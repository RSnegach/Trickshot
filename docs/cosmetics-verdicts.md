3. `static void SurfacePatch(Transform head, Material mat, Vector3 dir, Vector2[] outline, float standoff)`: polar FAN on the sphere (centre vertex + N outline verts + optional 1 inner ring for smoother shading). Outline points are tangent-plane METRES, CCW, centroid at origin; each maps to a direction exactly as HeadPatch does (yaw u/(HeadR) about up2, then pitch v/(HeadR) about side). Double-sided fan as in StippleDots. Replaces HeadPatch's rectangular grid (HeadPatch's only caller is the eyepatch, L882, so the signature can change).
4. Outline generators (return Vector2[] in metres): `Circle(r, n=32)`, `RoundedPoly(Vector2[] corners, float[] cornerRadii, int perCorner)` (rounded rect, wayfarer, half-moon), `Teardrop(w, h, tiltDeg, n)`. All must be star-shaped about the origin (fan triangulation) - every eyewear outline here is.
5. `static void SweptTube(Transform head, Material mat, Vector3[] dirs, float[] standoff, float rW, float rH, int sides, bool closed, float[] profileScale = null)`: at sample i, centre = dirs[i]*(HeadR+standoff[i])*_cosScale; frame = tangent (neighbour difference), radial (= dir), binormal (cross); ring of `sides` verts (rW along binormal, rH along radial, scaled by profileScale[i]); quads between consecutive rings; `closed` joins last->first. Wire = 6 sides rW=rH; acetate = 8 sides rW!=rH. Rim dirs come from the same outline->direction mapping as (3); temples/bridges/cords come from a Slerp path (`PathDirs(from, to, bow, n)` extracted from HeadLine.DirAt). A closed SweptTube on a spherical circle IS the torus the monocle needs; no separate Torus() or Lathe() required for this group.
6. `static void HeadBand(Transform head, Material mat, float standoff, float thetaFrom, float thetaTo, Func<float, Vector2> extents, int cols)`: generalised HeadRing - partial azimuth span, lifted off the sphere, per-column (phiTop, phiBot) so the height can taper and notch. Keep the existing HeadRing (headband caller at L1100) untouched. Used by the visor shield, the goggle foam ring and the goggle strap.
7. `static void SurfBlk(Transform head, Material mat, Vector3 dir, float standoff, Vector3 size)`: Blk oriented with Quaternion.LookRotation(dir, up) at dir*(HeadR+standoff) - hinges, monocle stud, goggle buckle. Today Blk is axis-aligned only.

## masks
SHARED INFRA: All five verdicts survive; the shared toolkit below is what makes them buildable. Code-verified constraints that shaped it: (1) HeadPatch (Cosmetics.cs L324) is a 12x8 small-angle swing grid at HeadR+0.004 with UVs 0..1 - it cannot take a bulge, a wide angular span (>~40 deg distorts), or give a rim edge; masks need new grid helpers. (2) The HairCard shader (Resources/Shaders/HairCard.shader) is NOT a decal path: frag uses tex2D(_MainTex).r ONLY as opacity, baseCol = _Color (texture RGB ignored) and it lights Kajiya-Kay with mesh.normals as strand tangents - a mask on it renders as a sheet of hair. Use the Standard shader in cutout mode instead: it is in Always Included Shaders (ProjectSettings/GraphicsSettings.asset m_AlwaysIncludedShaders fileID 46) so the _ALPHATEST_ON variant survives a build. (3) Crew cut = RootMode.Crown with phi 0.03..1.45 rad (down to 83 deg = brow) and staticToHead cards 0.075 long (Cosmetics.cs L721-723, HairSim.cs RootDir default case), so ANY Headgear=false shell over the forehead is pierced by roots underneath it - the fix is a root keep-out, not geometry. (4) HeadLine/HeadRing sit at HeadR+0.004, UNDER the CrownPatch (HeadR+0.006, covers phi 0..60 deg from the crown, Cosmetics.cs L627): a strap routed through phi<60 deg on a haired head is buried; shells must be >=+0.008 proud where they overlap the crown band. (5) EmitHeadGrid emits both windings over the same verts, so mesh.RecalculateNormals() would cancel - bulged shells need analytic normals. (6) AccessoryEntry.Build is (Transform, Material) with no ragdoll access; Glass()/Dark() (L1128-1129) already leak per call by admission. (7) PropKit.Place (PropKit.cs L96-122) sets isStatic=true and grounds the model - unusable for a head cosmetic; PropKit.Load + Instantiate(prefab, head) + Recolor is the right path.

1) Lathe(Transform head, Material[] mats, Vector2[] profile /* (r,y) */, bool[] hard, int segments, Func<Vector3,Vector3> warp = null, Func<int,int> segSubmesh = null). A solid of revolution about local Y from an ARBITRARY polyline profile (closed loops allowed, so a beret/brim can have a modelled underside instead of relying on double-sided emit). hard[i] duplicates the ring at that profile point so crown/brim junctions and flat tops get a crease; smooth elsewhere via RecalculateNormals after the warp. UVs u = theta/2pi, v = normalised profile arclength (needed by any optional woven/striped texture). warp runs on every vertex BEFORE normals; callers must weight brim warps by the radial fraction s = (r - rInner)/(rOuter - rInner) so the inner edge stays welded to the crown. segSubmesh lets alternate columns go to a second material (party-hat stripes) with no texture. Helper OffsetProfile(pts, t) turns an open profile into a thin closed shell for brims (gives edge thickness for free). Torus/ring/lip = Lathe of a small circle or 2-point profile, so no separate Torus helper is needed for this group.

2) SweepTube(head, mat, Func<float,Vector3> curve, Func<float,float> radius, int rings, int segs, float proud = 0): tapered tube along a curve with a stable frame (curve is planar in the y-z plane for the Wizard so side = +X, up = tangent x side; use parallel transport when it is reused for tusks/pipe stems in other groups). Emits caps closed at the tip.

3) EmitHeadMesh overload taking Material[] + submesh triangle lists, and an optional localRotation on the emitted "cz" object. Rotating a finished hat ABOUT THE HEAD CENTRE (the cz object's origin) keeps any sphere-flush ring flush, because the sphere maps to itself; use this for every tilt (party 8 deg, beret lean, fedora/cowboy 4-5 deg pitch) instead of moving vertices off the sphere.

4) LoftGrid(verts, cols, rows, mat, twoSided:false) + RecalculateNormals: single-sided grid emit with real normals (the existing double-sided EmitHeadGrid cannot shade an underside correctly and doubles tris). Used by the Peaky Cap crown/peak loft and the Trapper fallback flaps.
